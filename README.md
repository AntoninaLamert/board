# Доска задач

Откройте `index.html` в браузере. Интернет, сервер и установка пакетов не нужны.

Визуальная тема основана на переданных переменных TweakCN. Они перенесены в обычный CSS без Tailwind. Шрифты DM Sans и Space Mono, а также кириллические варианты Manrope и PT Mono находятся в папке `fonts` вместе с лицензиями, поэтому оформление работает без подключения к интернету.

На доске есть четыре начальные колонки. Дважды нажмите на название колонки, чтобы изменить его прямо в заголовке (на сенсорном экране — дважды коснитесь). Цвет колонки выбирается из палитры кнопкой в её шапке. Пунктирная плитка внутри колонки добавляет карточку в неё. Отдельная плитка справа создаёт карточку в новой колонке. Доска автоматически записывается в локальное хранилище браузера при изменениях и восстанавливается при следующем запуске. Файл TXT можно использовать как отдельную резервную копию или для переноса доски.

Нажмите на карточку, чтобы изменить её название и описание. Цвет карточки меняется нажатием на цветную полоску слева. Значки корзины удаляют карточку или колонку. Если в колонке есть карточки, приложение попросит подтвердить удаление.

Переключатель слева от меню «Файл» меняет светлую и тёмную тему. При первом запуске используется системная тема; после ручного переключения выбор запоминается в браузере.

Меню «Файл» в правом верхнем углу сохраняет все доски в один текстовый файл `doska-zadach.txt` и загружает их из такого файла. Внутри файла — читаемый JSON в формате TXT: колонки, карточки, обложки, вложения, фон и корзина хранятся вместе. Старые файлы доски тоже загружаются. При ошибке загрузки текущие данные остаются без изменений.

Вкладки сверху переключают доски. Кнопка `+` создаёт новую; двойной клик по вкладке меняет её название. Кнопка **«◐ Фон» рядом с названием приложения** открывает готовые фоны, загрузку своей картинки и переключатель «Живой фон». Загруженная картинка показывается в этом окне небольшим превью. Живой фон добавляет мягкие движущиеся световые пятна поверх выбранного фона; при системном ограничении анимации пятна остаются неподвижными. Фон и анимация сохраняются отдельно для каждой доски, попадают в автосохранение и TXT-файл. Поиск временно скрывает неподходящие карточки. Остальные кнопки в шапке включают компактный вид, звуки, корзину, презентацию, печать и одну из пяти тем. Звуки при каждом открытии страницы выключены; после включения звучат только короткие сигналы действий. Масштаб меняется кнопками `−` и `+` внизу справа.

Кнопка 📎 прямо на плитке существующей карточки открывает выбор изображения или файла. Прикреплённая картинка появляется маленьким превью на этой плитке. В форме создания или редактирования карточки раздел «📎 Изображения и файлы» расположен сразу под обложкой; там же можно скачать или убрать вложение. Обложка — отдельное изображение в верхней части карточки, её цвет подбирается автоматически. В форме также можно добавить стикеры и чек-лист, закрепить, заблокировать или увеличить плитку. Замок на плитке снимает блокировку; заблокированную карточку нельзя редактировать или переносить. Удалённые карточки и колонки восстанавливаются из корзины. Кнопка копирования в колонке дублирует её вместе с карточками. Колонку можно свернуть, а её иконку выбрать в шапке. Двойной клик по пустому месту колонки открывает создание карточки.

Обложки и прикреплённые изображения сжимаются при загрузке. Исходное изображение может занимать до 15 МБ, другой файл — до 2 МБ; все вложения одной карточки после обработки — до 3,5 МБ. Вложения входят в автосохранение браузера и экспортируемый TXT-файл. Если хранилище браузера заполнится, приложение предложит сохранить TXT-файл.

Карточки можно перетаскивать внутри колонки, между колонками и на крайнюю пунктирную плитку, чтобы создать новую колонку. Мышью карточку можно взять за свободную часть плитки; на сенсорном экране используйте значок захвата на карточке, чтобы обычный свайп по плитке продолжал прокручивать доску. Для перестановки колонок используйте значок захвата в их шапке. Во время перетаскивания доска прокручивается, если подвести указатель к её краю. Клавиша Escape отменяет перенос. На клавиатуре значки захвата поддерживают стрелки: вверх и вниз для карточек, влево и вправо для карточек и колонок.

Локальная проверка: `node smoke-test.cjs`.

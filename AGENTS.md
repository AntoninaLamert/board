# Работа с доской

- Это исходники сайта `https://antoninalamert.github.io/board/`.
- После изменения приложения проверяйте его командой `node smoke-test.cjs`.
- Завершённые изменения фиксируйте коммитом и отправляйте в `origin/main`. Пользователь разрешил синхронизацию с GitHub без отдельного подтверждения.
- Не записывайте токены в файлы проекта или адрес удалённого репозитория. Доступ к GitHub хранится в Git Credential Manager.
